# KepperNotes

A note-taking app built with React and Vite. Easily create, manage, and store your notes with a clean and responsive user interface.

## Features

- **Create and manage notes**: Add, edit, and delete notes.
- **Responsive design**: Works seamlessly on both desktop and mobile devices.
- **Fast and lightweight**: Powered by Vite for optimized performance.

## Tech Stack

- **React**: A JavaScript library for building user interfaces.
- **Vite**: A fast, next-generation bundler and development server.
- **JavaScript (ES6)**: Modern JavaScript features and syntax.
- **CSS**: Styling for the app's interface.
